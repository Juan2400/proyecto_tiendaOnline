# Proyecto Django - Tienda de Productos Personalizados

Este es un proyecto en Django para una tienda online de productos comestibles personalizados.

## Estructura del proyecto

- `app_inicio`: Página principal.
- `app_productos`: Gestión y personalización de productos.
- `app_galeria`: Galería de productos o trabajos anteriores.
- `app_nosotros`: Información sobre la empresa.
- `app_pagos`: Integración con pasarelas de pago.
- `app_carro`: Carrito de compras.
- `app_pedidos`: Gestión de pedidos.

## Requisitos

- Python 3.10+
- Django 4.x
- PostgreSQL
